# Cormorant Garamond

`CormorantGaramond-Regular.ttf` is bundled for the Open Graph and Twitter image
renderer. It is loaded from disk, together with the existing logo; generating a
social image does not fetch fonts or image assets over the network.

Source: https://github.com/CatharsisFonts/Cormorant/tree/master/fonts/ttf

The unmodified font is distributed with its upstream `OFL.txt` license and
`FONTLOG.txt` history. These files were retrieved from the same upstream repository.
